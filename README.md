# BIC21203 Web Development — Lab 4a

## Introduction
This repository contains my Lab 4a JavaScript exercises for BIC21203 Web Development. The lab demonstrates basic client-side scripting using HTML and JavaScript.

## Objectives
- Learn how to manipulate HTML elements using JavaScript.
- Handle user input and conditional statements.
- Generate HTML list elements dynamically using a loop.

## Project Structure
- **Q1:** Interactive Text Changer
- **Q2:** Smart Number Validator
- **Q3:** Dynamic Number Generator
- **screenshots:** Screenshots of the program outputs

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required question folder (Q1, Q2, or Q3).
4. Open `index.html` using Live Server.
5. Interact with the buttons and input fields to test the program.
